# train-12306 · 火车票查询比价

查火车票的本地网页工具：直达车次 + **12 枢纽并行中转方案** + 机票深链比价，
端口 **8831**。数据来自 12306 官方接口，零三方依赖（Python 标准库 + requests）。

## 功能

| 模块 | 说明 |
|------|------|
| 直达查询 | 车次/历时/余票/**全席别真实票价**，按历时/价格/出发时段排序筛选 |
| 智能中转 | 无直达或直达太贵时，自动并行查 12 个枢纽站的接续方案，算总历时+总价 |
| 机票比价 | 同线路机票一键深链（携程/同程），火车飞机横向比 |
| 持久缓存 | 车次/票价/车站名落库，**中转段预热后直达查询毫秒级** |

## 启动

双击 `start.bat`（自动开浏览器到 http://127.0.0.1:8831 ），或：

```bat
python server.py
```

本机 `python` 命令异常时：在项目根放 `python-path.txt`（已 gitignore），
内容为解释器全路径，start.bat 会优先读它。

## 数据库配置（可选）

默认零配置走 **SQLite**（`cache.db`，自动建表）。有 MySQL 可切换获得
跨实例共享缓存：复制 `db_config.example.json` 为 `db_config.json`（已 gitignore）填自己的连接：

```json
{
  "mysql": {
    "host": "127.0.0.1", "port": 3306,
    "user": "root", "password": "你的密码", "database": "train12306"
  }
}
```

两种模式**缓存键完全同源**，换库不丢预热成果。

## 技术要点（踩坑实录）

- **票价解码**：12306 的价格接口 / lcquery / 携程 API 均已失效（实测），
  现价只能从车次列表返回的**字段 39 `yp_info`** 按席别位图解码——本项目核心Know-how
- 车站电报码表 `stations.json` 本地化，站名模糊匹配不走网络
- 中转采用枢纽城市白名单并行扇出 + 结果按总耗时收敛，单查询串行预算可控
- 12306 接口带浏览器 UA/Cookie 模拟，仅 GET 只读查询，无登录无下单
